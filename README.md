# codemap-site

The site, docs and offer for [codemap](https://github.com/JordanCoin/codemap). Astro with Starlight for `/docs`.

```bash
npm install
npm run dev
npm run build
```

Set `PUBLIC_POSTHOG_KEY` at build time to enable analytics; unset, no analytics script loads.

Every sentence on the site follows the codemap [output standard](https://github.com/JordanCoin/codemap/blob/main/docs/OUTPUT-STANDARD.md).
